## 🚀 About Us

**Dadi Bara Dev** adalah tim pengembang teknis di bawah naungan **Karang Taruna Dadi Bara**. Kami bertugas merancang, membangun, dan memelihara seluruh infrastruktur digital—mulai dari sistem informasi publik, platform kegiatan pemuda, hingga layanan digital masyarakat lokal.

* 💡 **Misi:** Modernisasi ekosistem digital Karang Taruna dengan *stack* modern & standar industri.
* 🛠️ **Fokus Utama:** Performance, Clean Code, UI/UX modern, dan kolaborasi open-source.

## 🤝 How to Contribute

Kami sangat terbuka untuk kontribusi internal dari pengurus maupun pemuda Karang Taruna Dadi Bara!

1. Fork/Clone repository proyek tujuan.
2. Buat branch fitur baru (`git checkout -b feature/FiturBaru`).
3. Kirim Pull Request (PR) untuk direview oleh tim Lead Dev.
